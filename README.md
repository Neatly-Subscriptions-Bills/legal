## GitHub Pages setup

In this repository, enable GitHub Pages:

1. Open `Settings`.
2. Open `Pages`.
3. Under `Build and deployment`, choose `Deploy from a branch`.
4. Select branch `main` and folder `/root`.
5. Save.

The page uses English by default and provides a Ukrainian language switcher.
